# Runxi Shen — homepage

Personal website of **Runxi Shen**, computational biologist at Purdue University.

- Live: https://runxi-shen.github.io/homepage/
- [CV](https://runxi-shen.github.io/cv/) · [Talks & slides](https://runxi-shen.github.io/talks/) · [Carpenter–Shen Lab](https://carpentershenlab.org)

## Development

Static HTML/CSS/JS. No build step or dependencies.

```sh
python3 -m http.server 8000
```

Edit `index.html`, `style.css`, and `script.js`; replace `headshot.jpg` or
`fishing.jpg` to update the photos.

## Deploy

GitHub Pages, `main` branch, `/ (root)`. Push to deploy.
